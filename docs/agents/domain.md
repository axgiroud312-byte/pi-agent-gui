# Domain docs

采用 **single-context**：根 `CONTEXT.md` 与 `docs/adr/`。

## Before exploring

探索前读取根 `CONTEXT.md`，以及与当前工作相关的 ADR。当前工程基线决策为 `docs/adr/0001-native-zcode-base.md`；产品目标和实施顺序分别在 `docs/product-goal.md`、`docs/delivery/native-rebase-plan.md`。若以后出现 `CONTEXT-MAP.md`，先按其指针读取相关上下文。只有形成领域定义或值得记录的架构取舍时才补充。

## Vocabulary and decisions

Issue、测试名称和实现讨论沿用领域词汇。`CONTEXT.md` 是词汇表，实现方案与验收条件记录在规格 Issue。与已有 ADR 冲突时明确指出冲突，说明需要重议的决定。
