# Triage labels

| Matt canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待评估 |
| `needs-info` | `needs-info` | 待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不实施 |

五个角色与同名 GitHub 标签一一对应。技能提到角色时使用表中的实际标签。大型规格可以标记 `ready-for-agent`，供后续拆票；是否可开始实施还取决于阻塞项是否解除。
