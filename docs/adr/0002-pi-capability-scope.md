# 功能范围由 Pi 和必要桌面使用决定

2026-09-27 用户明确要求映射 Pi 的能力，并保留使用 Pi 必需的本地桌面体验。此前把 ZCode 的远程、完整 IDE 和扩展业务全集作为必做，扩大了产品目标；现保留 ZCode 原生 UI 底座和 Pi RPC 主会话架构，把功能完成合同收缩为 [当前范围](../delivery/pi-first-scope.md)。

代价是部分原生入口只保留可复用实现或明确不支持，复杂 TUI 兼容需要按接口说明限制；收益是每项新开发都有 Pi 能力或本地使用的明确依据。Pi 公开能力不因基础 RPC 缺少命令而删掉，可用公开桥/宿主映射；扩展兼容不要求自建 Plan、MCP、子 Agent 或调度业务系统。旧代码、任务历史与证据保留，退出票标为不计划实施。
