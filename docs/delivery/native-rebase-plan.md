## 后续：Pi 映射与必要桌面体验

以 [任务清单](full-development.md) 的 15 张功能票为准：对话/队列、本地项目与会话、树/历史、认证/模型/配置、llama、资源/扩展，以及文件引用、中文交互和可靠交付。基础 RPC 缺口可通过公开 API、扩展桥和必要宿主适配补齐；不另建 Agent loop。

#15–#24 退出首版；其必要的小部分已在保留任务明确承接。旧代码和分支按 [复用清单](reuse-inventory.md) 留存，不整批合并旧 UI，也不因复用扩大范围。复杂扩展 TUI 按 #8/#25 记录兼容边界。

## 最终：#28 与用户验收

[覆盖账本](coverage.md) 的每项当前能力和场景都有原生链路证据，相关本地验证及 Standards/Spec 审查通过后，交付可启动、可试用的 Windows 版本。在线 provider、受控模型、实际 Pi、包内启动和安装器分别报告。最终停在用户验收，不自动增加其他功能。

远程 CI 自 2026-09-27 起取消；纯文档/流程变更只做相关验证，见 [CONTRIBUTING](../../CONTRIBUTING.md)。
